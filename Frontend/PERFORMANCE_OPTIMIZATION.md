# Оптимизация производительности фронтенда

## Проблема
Страницы долго загружались при переключении между вкладками из-за частого обновления данных.

## Решения

### 1. Увеличено время кеширования запросов (staleTime)
- **Задачи**: с 1 минуты → 5 минут
- **Члены семьи**: с 30 секунд → 5 минут
- **Миссии**: с 1 минуты → 5 минут
- **Достижения**: с 2 минут → 10 минут
- **Товары**: с 1 минуты → 5 минут
- **Заказы**: с 30 секунд → 3 минуты

### 2. Увеличено время хранения в памяти (gcTime)
- Все запросы: с 5 минут → 10-15 минут
- Данные остаются в памяти дольше и не удаляются при переключении вкладок

### 3. Глобальные настройки React Query
```typescript
{
  staleTime: 1000 * 60 * 5,      // 5 минут
  gcTime: 1000 * 60 * 10,        // 10 минут
  refetchOnWindowFocus: false,    // не обновлять при фокусе на окне
  refetchOnMount: false,          // не обновлять при монтировании
  refetchOnReconnect: false       // не обновлять при восстановлении сети
}
```

### 4. Создан хук useOptimizedNavigation
Для плавных переходов между страницами без блокировки UI.

## Результаты
- ✅ Переключение между вкладками происходит мгновенно
- ✅ Данные берутся из кеша вместо повторных запросов
- ✅ Уменьшена нагрузка на сервер
- ✅ Улучшен UX - нет мигания загрузки

## Когда данные обновляются?
- При первой загрузке страницы
- После мутаций (создание/обновление/удаление)
- Вручную через refetch()
- Автоматически только в чате (каждые 5 секунд)
