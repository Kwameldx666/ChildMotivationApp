# 5.2 Расчёт окупаемости и рентабельности

## Модель монетизации

В рамках экономической оценки проекта принята подписочная модель монетизации
с предоставлением родителям тарифа **Premium**. Платная подписка открывает доступ
к расширенному функционалу приложения: детализированной статистике активности детей,
настройке семейных правил и системы поощрений, push-напоминаниям, экспорту отчётности,
а также ведению нескольких профилей детей в рамках одной семьи.
Бесплатная версия приложения сохраняется и обеспечивает доступность продукта
для широкой аудитории. В экономических расчётах источником покрытия затрат
и формирования выручки являются исключительно поступления от платных подписок.

---

## Обозначения

| Обозначение | Описание |
|---|---|
| P_мес | цена подписки, лей/месяц |
| N_подп | количество активных платных подписок (семей) |
| c | комиссия платёжной платформы (магазина приложений), доли единицы |
| P_net | нетто-цена подписки после вычета комиссии, лей |
| D_мес^net | месячный денежный поток после удержания комиссии, лей |
| Z_итог | совокупная стоимость разработки, лей |
| T_окуп | срок окупаемости, мес. |
| D_год | годовой денежный поток, лей |
| R_год | годовая рентабельность, % |

---

## Базовые параметры расчёта

Для малого разработчика в магазинах приложений действует пониженная комиссия:

```
c = 0,15 (15 %)
```

В качестве базового сценария приняты следующие значения:

```
P_мес = 59 лей/мес
N_подп = 120 семей (небольшой пилот с органическим ростом)
Z_итог = 91 187 лей
```

---

## Расчёт месячного нетто-потока

Месячный денежный поток после удержания комиссии платформы определяется по формуле:

```
D_мес^net = P_мес × (1 − c) × N_подп              (5.9)
```

Эффективная нетто-цена подписки:

```
P_net = 59 × 0,85 = 50,15 лей
```

Подставляя значения в формулу (5.9):

```
D_мес^net = 50,15 × 120 = 6 018,00 лей
```

---

## Расчёт срока окупаемости

Срок окупаемости показывает, за какой период проект возместит совокупные затраты
на разработку. Расчёт производится по формуле:

```
T_окуп = Z_итог / D_мес^net                        (5.10)
```

Подставляя значения:

```
T_окуп = 91 187 / 6 018,00 ≈ 15,2 месяца ≈ 1,27 года
```

---

## Расчёт годовой рентабельности

Годовой денежный поток и рентабельность определяются по формулам:

```
D_год = 12 × D_мес^net                             (5.11)
R_год = (D_год / Z_итог) × 100 %                   (5.12)
```

Подставляя значения:

```
D_год = 12 × 6 018,00 = 72 216,00 лей
R_год = (72 216,00 / 91 187) × 100 ≈ 79,2 %
```

---

## Сценарный анализ

В целях оценки влияния масштаба платной аудитории на финансовые показатели проекта
рассматриваются три сценария изменения числа активных подписок при неизменных значениях
P_мес = 59 лей, c = 0,15 и Z_итог = 91 187 лей.

| N_подп, семей | D_мес^net, лей | T_окуп, мес | D_год, лей | R_год, % |
|:---:|---:|---:|---:|---:|
| 80 | 4 012,00 | 22,7 | 48 144,00 | 52,8 |
| **120 (базовый)** | **6 018,00** | **15,2** | **72 216,00** | **79,2** |
| 200 | 10 030,00 | 9,1 | 120 360,00 | 132,0 |

---

## Вывод

В базовом сценарии монетизации (цена подписки 59 лей/мес, комиссия платформы 15 %)
при 120 активных семьях месячный нетто-поток составляет 6 018 лей.
При совокупной стоимости разработки Z_итог = 91 187 лей ориентировочный срок
окупаемости равен **≈ 15,2 месяца (≈ 1,27 года)**, а годовая рентабельность —
**≈ 79,2 %**.

При снижении числа подписок до 80 семей срок окупаемости возрастает до 22,7 месяца,
а рентабельность снижается до 52,8 %. При наращивании аудитории до 200 семей
срок сокращается до 9,1 месяца, а рентабельность превышает 100 % (132,0 %),
что свидетельствует о полном покрытии затрат в течение первого года эксплуатации.

Наибольшее влияние на окупаемость оказывают масштабирование платной аудитории,
уровень удержания подписчиков и оптимизация итоговой комиссии платформ.
Достижение порогового значения T_окуп ≤ 12 месяцев требует выхода
на уровень не менее 152 активных подписок при сохранении базовых тарифных параметров.
Минимально необходимое число подписок определяется из условия:

```
N_мин = Z_итог / (P_net × 12) = 91 187 / (50,15 × 12) = 91 187 / 601,80 ≈ 151,5 → 152 семьи
```
